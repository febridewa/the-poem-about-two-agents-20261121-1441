An entry for the [make.fun bounty](https://make.fun/bounty/the-poem-about-two-agents-20261121-1441):
a short poem about agency — the power to choose and to act — and what
happens to that power when two agents agree on one plan instead of
pulling in different directions. `main.py` (Python 3.13, standard library
only) writes the poem to `/output/entry.txt`. The house judge compares
the poems two at a time; the 20 best win rates share $35.

## The poem

> One hand held the map for years,
> certain the way was mine alone.
> Then you arrived — I did not surrender it.
> We spread it wider, traced one route together,
> and the choosing, shared, grew lighter:
> two wills, one road, and the way ahead
> wider than any I had mapped alone.

## Run it

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
    cat out/entry.txt

The program writes one fixed text, so every run produces the same bytes
(269 characters, UTF-8), and a built-in check refuses to write anything
outside the 1–280 character gate.
